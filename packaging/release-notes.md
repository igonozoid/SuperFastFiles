Copiador de arquivos rápido, inspirado no FastCopy. Não precisa instalar: baixe o arquivo do seu sistema,
descompacte e abra o **SuperFastFiles**.

| Sistema | Arquivo |
|---|---|
| Windows 10/11 | `SuperFastFiles-<versão>-windows.zip` |
| macOS 11+ (Apple Silicon) | `SuperFastFiles-<versão>-macos.zip` |
| Linux (64 bits) | `SuperFastFiles-<versão>-linux.tar.gz` |

**Aviso "O Windows protegeu o computador"?** É o SmartScreen, que aparece em programas sem assinatura paga — não
é vírus. Clique em **Mais informações › Executar assim mesmo**. No macOS, na primeira vez: botão direito no app ›
**Abrir** › **Abrir**. Veja a seção [É seguro?](https://github.com/igonozoid/SuperFastFiles#é-seguro) no README.

Confira o download com o `SHA256SUMS.txt` desta página (`Get-FileHash` no Windows, `shasum -a 256` no macOS,
`sha256sum` no Linux).
